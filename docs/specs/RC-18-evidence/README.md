# RC-18 Public Evidence Excerpts

Captured through the public Yahoo Auctions Japan pages and the public web reader on 2026-10-27.

These sanitized excerpts preserve the visible outcome-relevant fields and their page role.
They are not raw HTTP payloads or HTML parser fixtures because the reader exposed extracted text, not response bodies.
Seller names, account names, seller ratings, locations, contact details, and tracking data are omitted.
The public auction IDs and source URLs remain because exact identity is part of the evidence being checked.

The excerpts are not a pass for the production writer gate.
The spec records each ambiguity and the resulting no-go decision.
